Đồng bộ với GitHub

Dữ liệu và hình được lưu vào thư mục data/ của repo, nên mở trên máy nào cũng thấy. Tạo token tại GitHub: Settings, Developer settings, Fine-grained tokens, chỉ chọn repo này, quyền Contents: Read and write. Token chỉ lưu trong trình duyệt của máy này, không nằm trong file trang. Đừng nhập trên máy dùng chung. Máy chưa nhập token vẫn xem được (chỉ xem).
